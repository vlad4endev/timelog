# TimeLog — учёт рабочего времени

PWA для фрилансера/разработчика с **почасовой оплатой**: таймер, округление часов, отчёты и контроль неоплаченного времени.

## Быстрый старт

```bash
cd ~/Projects/timelog
npx http-server . -p 8080
# Открыть http://localhost:8080
```

Или перетащите папку на [Netlify Drop](https://app.netlify.com/drop).

## Главное для почасовой оплаты

1. **Проект** — укажите ставку ₽/час (или другую валюту в настройках).
2. **Таймер** — старт → работа → стоп → подтверждение с суммой к оплате.
3. **Округление** — в Настройках: шаг 15/30/60 мин, округление вверх или до ближайшего.
4. **Отчёты** — период + проект → печать PDF для клиента.
5. **Оплата** — отметьте полученные платежи, видите остаток по проектам.

Настройки → Supabase → URL + anon key → SQL из интерфейса → «Подключить».

По умолчанию в `localStorage`. Экспорт/импорт JSON — в Настройках.
